## Data availability

Public third-party datasets used in this study are available from the original
providers identified in the manuscript and in the repository data-source
manifest. Machine-readable scenario tables and aggregate results that do not
contain the processed InSAR deformation products are archived with the
analysis code in Zenodo at https://doi.org/[ZENODO_VERSION_DOI]. The processed
SBAS-InSAR time series, deformation rasters, future-subsidence rasters and
subsidence-derived spatial masks are not included in the public archive.

## Code availability

The Python code used for vertical-datum harmonisation, AR6 and historical
water-level preparation, connected-inundation screening, population-exposure
calculation and quality-control diagnostics is available from GitHub at
[GITHUB_REPOSITORY_URL] and archived as release v1.0.0 in Zenodo at
https://doi.org/[ZENODO_VERSION_DOI].
